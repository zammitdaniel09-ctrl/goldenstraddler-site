Set it up in five minutes

Downloads Download GoldenStraddler.ex5 Download the user guide (PDF)

  1. Put the file in MT5. In MetaTrader 5 click File → Open Data Folder, open MQL5 → Experts and copy GoldenStraddler.ex5 in. Right-click Expert Advisors in the Navigator and choose Refresh.
  2. Allow its web address. Tools → Options → Expert Advisors: tick Allow WebRequest for listed URL and add: https://goldenstraddler.com
  3. Attach it to gold. Drag GoldenStraddler onto an XAUUSD chart, paste your licence key into the first input, and turn on Algo Trading in the toolbar.
  4. Leave MT5 running. It arms itself 15 seconds before every high-impact USD release. A Windows VPS keeps it online around the clock.
